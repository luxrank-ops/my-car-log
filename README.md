# 🚗 내 차 AI 차계부 (my-car-log)

이춘학 님의 3대(레이 26라2388 · 콜로라도 91머4445 · 임팔라 25거0986)를 스스로 관리하는 **로컬 PWA**입니다.
서버·DB·계정이 없습니다. 기록은 폰 브라우저(IndexedDB)에만 저장되고, 오프라인에서도 100% 동작합니다.

## 바로 쓰기 (홈 화면에 추가)

1. 폰 브라우저에서 아래 주소를 엽니다.
   - **https://luxrank-ops.github.io/my-car-log/**
2. Chrome(안드로이드): 오른쪽 위 ⋮ → **홈 화면에 추가**
   Safari(iOS): 공유 → **홈 화면에 추가**
3. 이후에는 아이콘을 누르면 주소창 없이 앱처럼 열립니다.

## 무엇이 들어 있나

| 기능 | 내용 |
|---|---|
| 초기 데이터 | 차량 3대 제원·보험·검사일, 레이 주유 8건(471,192원 / 258.31L), 브레이크 정비 4항목(421,344원) |
| 주유 기록 | 추가·수정·삭제, 단가·수량·금액 자동 계산, 구간 연비(만탱크법) 자동 계산 |
| 정비 기록 | 추가·수정·삭제, 소모품 12종 교체 주기 진행률 자동 갱신 |
| AI 빠른 입력 | 카드 결제 문자·메모·영수증 메모를 붙여넣으면 날짜·주유소·금액·단가·수량·주행거리 자동 추출 |
| 자동 진단 | 다음 주유 예측, 소모품·검사·보험 D-day, 연비 ±15% 하락 감지와 원인 후보 |
| AI 비서 | 내 차 실제 기록 + 취급설명서를 결합한 자연어 Q&A |
| 설명서 | 기아·쉐보레 공식 취급설명서 기반 40개 항목, 차량 필터 + 키워드 검색 + 하이라이트 |
| 엑셀 | SheetJS 로컬 번들, `.xlsx` 4시트(전체요약·주유기록·정비기록·차량정보) 원클릭 다운로드 |
| 백업 | JSON 전체 내보내기 / 복원 |

## 선택 기능 — Gemini API 키

설정 탭에 본인 Gemini 키를 넣으면 ①영수증 사진 OCR ②더 자연스러운 심층 답변이 켜집니다.
키는 **이 폰의 localStorage**에만 저장되고, 호출은 브라우저에서 Google API로 직접 나갑니다(중계 서버 없음).
키가 없어도 문자·메모 파서, 진단·예측, 매뉴얼 검색, 엑셀은 모두 그대로 동작합니다.

## 데이터·프라이버시

- 저장 위치: 브라우저 IndexedDB (`car-log-pwa` DB, `kv` 스토어) — 실패 시 localStorage 폴백
- 서버 전송 없음, 분석 도구 없음, 쿠키 없음
- 폰을 바꾸면 설정 → JSON 백업으로 옮길 수 있습니다

```

js/seed.js            최초 시드 데이터 (차량 3대·주유 8건·정비·소모품 주기·일정)

js/db.js              IndexedDB 저장·백업·복원

js/ai.js              연비·소모품·D-day 계산, 브리핑, Q&A, Gemini 연동
js/xlsx-export.js     SheetJS 다중 시트 엑셀
js/app.js             화면 렌더링·이벤트
vendor/xlsx.full.min.js  SheetJS 0.20.3 (로컬 번들, 오프라인)
sw.js                 서비스워커 (앱 셸 캐시 우선 + 오프라인 폴백)
manifest.json         PWA 매니페스트 (standalone, 아이콘 192/512/maskable)
tests/e2e.py          Playwright 실제 브라우저 검증 74항목
tests/serve.py        로컬 정적 서버
```

## 검증 결과

`python3 tests/e2e.py` — Chromium(390×844, Asia/Seoul)에서 74/74 통과:

- 시드: 차량 3대·주유 8건(471,192원)·정비 4항목(421,344원)
- 연비: 평균 12.39km/L, 일평균 31.9km, 다음 주유 2026-12-01 예측
- 파서: `[삼성카드] 60,000원 송산주유소 11/19` → 금액·주유소·날짜 추출 / `11/20 1819원 6만원 141545km` → 단가·금액·수량(32.985L)·주행거리
- 설명서: "엔진오일" 11건 검색·하이라이트, 레이 필터 6건, "4H"·"공기압"·"퓨즈" 검색
- AI: 엔진오일 2.9L / 보증 2026-11-25 / 4H·4L 모드 / 연비 실데이터 답변
- 엑셀: 다운로드 후 openpyxl 파싱 → 4시트·구간연비 6개 값 확인
- IndexedDB 영속성, 서비스워커 activated, 오프라인 재로딩, 오프라인 엑셀 생성
- 콘솔 오류 0, 430px 가로 스크롤 없음

## 다른 곳에 배포하려면

- **Cloudflare Pages**: `npx wrangler pages deploy . --project-name my-car-log` (정적 파일 그대로, 빌드 없음)
- **Vercel**: `npx vercel --prod` (저장소 루트를 그대로 서빙, `vercel.json` 포함)
- **자체 호스팅**: 아무 정적 서버에 폴더를 올리면 됩니다. HTTPS만 있으면 PWA 설치가 됩니다.
